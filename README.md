# Дурак (iOS, SwiftUI) — Monte Carlo бот

1. Залей папку в GitHub-репозиторий (ветка main).
2. Actions → "Build unsigned IPA" → скачай артефакт `Durak.ipa`.
3. Подпиши IPA своим сертификатом (Sideloadly / AltStore / zsign / Xcode).

Структуры данных и алгоритмы (свой код): DataStructures.swift, Algorithms.swift.
Правила: Engine.swift. Бот: MonteCarlo.swift.
